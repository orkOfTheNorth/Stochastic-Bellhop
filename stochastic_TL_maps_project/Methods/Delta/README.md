# Methods/Delta — Delta Method (First-Order Taylor) Results

Delta method UQ results for all scenario × distribution combinations.
Generated by `run_Delta.m`.

## Method Summary

First-order Taylor expansion around the nominal parameter vector θ₀:

```
TL(θ) ≈ TL(θ₀) + J'(θ − θ₀)

E[TL]   ≈ TL(θ₀)
Var[TL] ≈ Σᵢ∈S  Jᵢ² σᵢ²    (independent inputs)
```

Jacobians are computed via central finite differences using `computeJacobian.m`.
Step sizes are taken from `config.json` (`jacobian_steps`): Δfreq=50 Hz, ΔzS=0.025 m,
Δsvp=0.125 m/s. SVP Jacobians use `makeSVPNoise.m` to perturb the full profile.

## Directory Layout

```
Delta/<scenario>/<distribution>/
    results/
        delta_jacobians.mat      — J_freq, J_zS, J_svp (shared across distributions)
        delta_<subset>.mat       — Delta_Var, Delta_EX, cheb_bound, ln3_prob per subset
    figures/
        cheb_<subset>.png        — 4-colour categorical Chebyshev P(shadow) map (7 per combo)
        smooth_<subset>.png      — non-smooth | LPF | Gaussian smoothed Var maps (7 per combo)
Delta/<scenario>/
    shared_jacobians.mat         — Jacobians computed once, reused across all distributions
    delta_order_diff_absolute.png
    delta_order_diff_relative.png
```

## Notes

- Jacobians depend only on the scenario (nominal point), not on the distribution.
  `shared_jacobians.mat` is computed once per scenario to avoid redundant Bellhop calls.
- The Delta method is exact for linear models; for Bellhop TL fields it is a
  first-order approximation. See `findings.tex` for accuracy comparisons against MC.
- A second-order (Hessian) correction is available via `computeHessianDiag.m` and
  explored in `run_taylor2.m` / `plot_taylor_order_study.m`.
