# Methods/PCE — Polynomial Chaos Expansion Results

PCE variance estimates for all scenario × distribution combinations.
Generated by `run_pce.m` — no new Bellhop runs are performed; coefficients are
fitted by least-squares regression onto the existing MC TL samples.

## Method Summary

For each uncertain parameter p ∈ {freq, zS, svp} independently:

```
TL(ξ) ≈ Σ_{n=0}^{K*} c_n Φ_n(ξ)

Var_K = Σ_{n=1}^K c_n² γ_n    (Sobol variance decomposition)
```

Basis polynomials Φ_n: Legendre (Uniform distributions) or Hermite (Normal distributions).
Expansion order swept from 1 to 10; optimal order K* selected by L1-norm convergence.

## Directory Layout

```
PCE/<scenario>/<distribution>/
    results/
        pce_results.mat      — C_all, L1_mat, Kstar, VarK_best (see below)
    figures/
        pce_convergence_<scen>_<dist>.png  — L1 error vs order for each parameter
PCE/pce_summary_all.png      — summary convergence panel across all combos
```

## Saved Variables in pce_results.mat

| Variable | Description |
|----------|-------------|
| `C_all` | Cell array (3 params × MAX_ORDER) of PCE coefficient vectors |
| `L1_mat` | 3 × MAX_ORDER matrix of L1 approximation errors |
| `Kstar` | 3-element vector: optimal expansion order per parameter |
| `VarK_best` | 3-element vector: PCE variance estimate at K* per parameter |

## Notes

- PCE requires completed MC results (`MC_freq.mat`, `MC_zS.mat`, `MC_svp.mat`) to exist.
  Run `run_MC.m` first if they are missing.
- Only single-parameter subsets are modelled by PCE (multivariate PCE not yet implemented).
