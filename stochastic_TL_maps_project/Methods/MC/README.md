# Methods/MC — Monte Carlo Results

Monte Carlo UQ results for all scenario × distribution combinations.
Generated by `run_MC.m` using N=50 Latin Hypercube samples (seed 42).

## Directory Layout

```
MC/<scenario>/<distribution>/
    results/
        MC_freq.mat          — MC statistics for frequency uncertainty alone
        MC_zS.mat            — MC statistics for source-depth uncertainty alone
        MC_svp.mat           — MC statistics for SVP uncertainty alone
        MC_zS_freq.mat       — pair subset
        MC_zS_svp.mat        — pair subset
        MC_freq_svp.mat      — pair subset
        MC_zS_freq_svp.mat   — all three uncertain parameters
    figures/
        TL_<subset>.png              — E[TL] map with Var datatip (7 per combo)
        combined_EX.png              — all-7 E[TL] panels in one figure
        combined_Var.png             — all-7 Var[TL] panels in one figure
        cheb_<subset>.png            — 4-colour Chebyshev P(shadow) map (7 per combo)
        empirical_<subset>.png       — 4-colour empirical P(shadow) map (7 per combo)
```

## Saved Variables (per .mat file)

Each `MC_<subset>.mat` stores: `MC_EX`, `MC_Var`, `MC_PrFOM`, `r_grid`, `z_grid`,
`cheb_bound`, `ln3_prob`, and the raw TL cube used for empirical statistics.

## Caching

Bellhop runs are cached at two levels under `Cache/<scenario>/`:
- `bellhop_raw/` — individual Bellhop TL matrices keyed by parameter hash
- `<dist>/` — assembled TL cube per subset (avoids re-running Bellhop on re-runs)

The Cache directory is git-ignored. Delete it to force a full re-computation.
