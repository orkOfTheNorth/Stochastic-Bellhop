# Stochastic Bellhop UQ — Project README

Uncertainty Quantification (UQ) of underwater acoustic Transmission Loss (TL) using four methods:
Monte Carlo (MC), Delta/FOSM, Polynomial Chaos Expansion (PCE), and 3-parameter Lognormal (LN3).

## Sampling Design (Critical)

The pipeline uses **two separate N=1000 sample sets** per combo:

| Set | Sampling | Cache path | Used for |
|-----|----------|-----------|----------|
| LHS | Latin Hypercube | `Cache/<sc>/<dist>/` | MC mean/variance/P_detect, MOM-LN3, KDE, PCE |
| IID | Independent, i.i.d. | `Cache/<sc>/<dist>_iid/` | MLE-LN3 only |

**Why two sets?** MLE requires i.i.d. samples (for Cramer-Rao bound and valid confidence
intervals). MOM works with LHS samples (moment estimators are unbiased regardless of
stratification). Using the right samples for each estimator satisfies theoretical
assumptions exactly.

**Total Bellhop runs**: 4 × 3 × 3 × 2 × 1000 = **72,000**

#### Distribution comparison — `scripts/regenerate_pce_dist.m`

| Figure | Path | Description |
|--------|------|-------------|
| `pce_dist_<sc>_<dist>.png` | `Methods/PCE/<sc>/<dist>/figures/` | 3×3: MC histogram vs PCE(K*) histogram at 3 range slices |

**KNOWN BUG (FIXED in regenerate_pce_dist.m)**: The original `run_pce.m` fitted PCE on
**centred** TL (TL − mean(TL)), storing near-zero constant coefficients in `C_all`.
Naive reconstruction produces PCE histograms centred at ~0 dB instead of ~100 dB.
`regenerate_pce_dist.m` loads `MC_EX` from the MC results and adds the per-pixel mean
back to all PCE samples before plotting.

**Also**: Never use K=K_max=20 for evaluation — Hermite polynomials blow up at |ξ|>2.
Always use K=K* coefficients (`C_all{pi}(1:Kstar+1, :)`).

**To fix**: Delete `pce_dist_*.png`, run `scripts/regenerate_pce_dist.m`.

**KNOWN BUG (FIXED in regenerate_ln3_histograms.m)**: When LN3 PDF has a very narrow peak
(small σ, concentrated distribution), MATLAB auto-scales the y-axis to the PDF peak height
(e.g. 50 dB⁻¹), making the much shorter histogram bars (e.g. 0.5 dB⁻¹) nearly invisible.
The panel appears to show only a smooth curve with no histogram.

Fix: after plotting, `ylim(ax, [0, max(hist_vals)*1.3])` clips the y-axis to the
histogram range. The LN3 curve may extend above the axis limit — this is intentional.

**To fix**: Delete `LN3_<param>.png` files, run `scripts/regenerate_ln3_histograms.m`.

## How to Run the Full Pipeline

```matlab
% MATLAB — working directory must be stochastic_TL_maps_project/
addpath(genpath('core')); addpath('pipeline'); addpath('scripts');

run_mc          % Step 1: LHS + IID TL cubes → MC statistics + LN3-MLE
run_delta       % Step 2: FOSM Jacobians, variance maps, shadow bounds
run_pce         % Step 3: PCE fitting with LOO-CV order selection
run_ln3         % Step 4: LN3 KS fit quality maps
run_comparison  % Step 5: Cross-method comparison figures
```

Each script uses `skipIfDone()` — it will skip combos where output `.mat` already exists.
To force regeneration: delete the relevant output file, then re-run.

## Known Issues and Fixes

| Issue | Symptom | Root cause | Fix |
|-------|---------|-----------|-----|
| **PCE histogram mean ≈ 0 dB** | `pce_dist_*.png` shows PCE bars at 0 instead of 100–120 dB | `run_pce.m` fitted on centred TL; reconstruction forgets to add mean back | `scripts/regenerate_pce_dist.m` (adds `MC_EX` back) |

| **PCE Hermite blow-up** | Convergence curves collapse above K≈15 | High-order He polynomials blow up at \|ξ\|>2 | `scripts/regenerate_pce_individual.m` (ylim clipped) |
